# Daily AI Agent product-source imports

`original/` contains byte-for-byte snapshots of the supplied Daily AI Agent
source package. The root copies and the members of
`/home/rosso/Downloads/daily-agent-blueprint.zip` were SHA-256 identical at
the recorded import time; no conflicting copy was found.

`SOURCE_MANIFEST.json` is the current versioned inventory with source path,
archive member, imported path, SHA-256, source revision/status, and import
time. `IMPORT_AUDIT.jsonl` preserves the earlier missing-source record and the
append-only verified import event. Do not edit a file under `original/`; import
a new source revision under a distinct path and add a new manifest/audit entry.

The current constraint consumer is
`docs/live_pilots/router-constraint-map-v0.2.0.json`. Its entries cite source
file, heading, and source hash. An imported source is not a measured provider
result: prices, quotas, provider allowlists, production cost ceilings, launch
geography/channel eligibility, and measured staging evidence remain explicit
`UNRESOLVED_OWNER_INPUT` values until their owner records them.
